# DESAFIO REACT



## PRINCIPAIS COMANDOS

### BAIXE O PROJETO

- Clone o repositório para seu computador

- Ou baixe o projeto (pode ser o `.zip`, pelo botão verde na página escrito **Code**)

- Entre na pasta `desafio-react`, instale as dependências:

    ```bash
    npm i
    ```

### RODAR A API FAKE

- Inicie a API Fake:

    ```bash
    npm run server
    ```

### RODAR O PROJETO

- Para rodar o projeto:

    ```bash
    npm run dev
    ```
